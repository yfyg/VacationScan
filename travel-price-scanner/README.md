# סורק מחירי טיסות + מלונות

אפליקציית Node.js/Express קטנה שסורקת את **Google Flights** ו-**Google Hotels** (דרך [SerpApi](https://serpapi.com)) על טווח תאריכים שאתם מגדירים, ומציגה את קומבינציית טיסה+מלון הזולה ביותר.

## איך זה עובד

1. אתם מגדירים "טיול" ב-`config.json`: נמל תעופה יעד ומוצא, יעד/רשימת מלונות ספציפית (אופציונלי), טווח תאריכים, טווח מספר לילות, כמות אורחים.
2. בכל טעינת עמוד (או לחיצה על "סרוק עכשיו") השרת מייצר את כל הקומבינציות האפשריות של (תאריך צ'ק-אין, מספר לילות) בתוך הטווח, ולכל קומבינציה שולח שתי שאילתות ל-SerpApi: אחת ל-Google Flights (טיסה הלוך-חזור) ואחת ל-Google Hotels (המלון/המלונות שהוגדרו, או המחיר הזול ביותר באזור אם לא הוגדרו מלונות ספציפיים).
3. התוצאות נשמרות במטמון (`data/cache.json`) לפי מספר השעות שהגדרתם (`cacheHours`, ברירת מחדל 24) - כך שטעינות חוזרות באותו יום לא צורכות שוב מכסת API.
4. הדף מציג את הקומבינציה הזולה ביותר בבלוק מודגש, ואת כל הקומבינציות שנסרקו בטבלה.

## הרצה מקומית

```bash
npm install
cp .env.example .env      # ומלאו את SERPAPI_KEY שלכם
cp config.example.json config.json   # ועדכנו יעד/תאריכים/מלונות
npm start
```

לאחר מכן פתחו [http://localhost:3000](http://localhost:3000).

להרצת בדיקות היחידה (לא דורשות מפתח API, בודקות רק את לוגיקת ייצור הקומבינציות):

```bash
npm test
```

## קבלת מפתח SerpApi

נרשמים ב-[serpapi.com](https://serpapi.com/users/sign_up) ומעתיקים את המפתח הפרטי מהדשבורד. **תוכנית חינמית: 250 חיפושים בחודש, מקסימום 50 בשעה.** כל קומבינציית (צ'ק-אין, לילות) שנסרקת "עולה" 2 חיפושים (טיסה + מלון), אז 24 קומבינציות בסריקה = 48 חיפושים. שימו לב לזה בקביעת `maxCombosPerScan` ו-`cacheHours` בקונפיג, כדי לא לגמור את המכסה החינמית.

## מבנה config.json

ראו `config.example.json` לדוגמה מלאה. שדות עיקריים לכל טיול ברשימת `trips`:

| שדה | משמעות |
|---|---|
| `departureAirport` / `destinationAirport` | קודי IATA (למשל `TLV`, `BCN`) |
| `destinationQuery` | מחרוזת חיפוש ל-Google Hotels (למשל `"Barcelona hotels"`) |
| `hotels` | רשימת שמות מלונות לסינון (אופציונלי - מערך ריק = המחיר הזול ביותר בכל האזור) |
| `dateRange.start` / `dateRange.end` | טווח התאריכים לסריקה (YYYY-MM-DD) |
| `nights.min` / `nights.max` | טווח מספר הלילות לשהייה |
| `guests.adults` / `guests.children` | כמות אורחים |
| `scanLimits.maxCombosPerScan` | תקרת קומבינציות לסריקה אחת (הגנה על המכסה) - אם יש יותר קומבינציות אפשריות, נדגמות באופן שווה על פני הטווח והממשק מציג כמה דולגו |
| `scanLimits.cacheHours` | כמה שעות לשמור תוצאה במטמון לפני שסורקים אותה מחדש |

ניתן להגדיר כמה טיולים במערך `trips` ולבחור ביניהם בתפריט הנפתח בעמוד.

## פריסה כאתר חי

האפליקציה היא שרת Node.js רגיל (לא serverless), אז המסלול הפשוט ביותר הוא אחסון עם דיסק מתמשך:

### Render (מומלץ, יש שכבה חינמית)
1. דחפו את הפרויקט ל-repo ב-GitHub.
2. ב-[render.com](https://render.com) → New → Web Service → מחברים את ה-repo.
3. Build command: `npm install`, Start command: `npm start`.
4. ב-Environment מוסיפים את `SERPAPI_KEY`.
5. **חשוב**: מוסיפים גם Persistent Disk קטן (Render מאפשר דיסק חינמי קטן) ומצמידים אותו לתיקיית `data/` כדי שהמטמון יישמר בין הפעלות. בלי דיסק מתמשך, המטמון יתאפס בכל דיפלוי/הפעלה מחדש (זה עדיין עובד, רק מבזבז יותר מכסת API).
6. את `config.json` צריך גם להעלות ל-repo (או להגדיר כ-Secret File ב-Render) - שימו לב שהוא ב-`.gitignore` כברירת מחדל כדי שלא תעלו בטעות תאריכים/מלונות פרטיים; הסירו אותו מ-`.gitignore` אם אתם בסדר עם זה בריפו הפרטי שלכם.

### Railway / Fly.io
תהליך דומה - שירות Node.js רגיל עם `npm start`, משתנה סביבה `SERPAPI_KEY`, ודיסק מתמשך לתיקיית `data/` אם רוצים מטמון אמין.

### Vercel
Vercel מריץ פונקציות serverless חסרות דיסק מתמשך, כך שהמטמון הקבצי לא יעבוד בצורה עקבית (רק best-effort בתוך instance חם בודד). אם אתם רוצים בכל זאת Vercel, אפשר לחבר Vercel KV/Upstash Redis במקום `data/cache.json` - זה שינוי קטן ב-`src/lib/cache.js` שאפשר לבקש בהמשך.

### הרצה על המחשב שלכם באופן קבוע
`npm start` (או עם `pm2`/`forever` כדי שירוץ ברקע) - נגיש רק במחשב עצמו, אלא אם תחשפו אותו לאינטרנט (למשל עם [ngrok](https://ngrok.com) או port forwarding).

## הערות

- ה-scraping כאן הוא למעשה קריאות API חוקיות ל-SerpApi (שירות צד-שלישי המורשה לגשת לתוצאות Google), ולא scraping ישיר של Google - זה נמנע מהחסימות/CAPTCHA שגוגל מפעילה נגד גישה אוטומטית ישירה, ונשאר בגבולות תנאי השימוש.
- מחירי מלונות מ-Google Hotels הם "לפחות X" ולא כוללים בהכרח מיסים/עמלות מלאים - שווה לאמת את המחיר הסופי באתר ההזמנה בפועל לפני רכישה.
