סורק מחירי טיסות + מלונות

מבוסס על Google Flights ו-Google Hotels (דרך SerpApi). מתעדכן אוטומטית לפי לוח הזמנים ב-GitHub Actions.
רוצה סריקה מיידית ולא לפי לוח הזמנים? כניסה לריפו ב-GitHub → לשונית Actions → Scan travel prices → Run workflow. הדף הזה יתעדכן אוטומטית לאחר שהסריקה תסתיים ותידחף לריפו (כמה עשרות שניות עד דקה-שתיים).
